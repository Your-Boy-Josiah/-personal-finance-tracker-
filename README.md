  ## Banking Integration Commit (Mono API)
This module handles secure bank linking and transaction synchronization using the Mono API. All access tokens are encrypted using AES-256-GCM before being stored in MongoDB.

### Endpoints
* **`POST /api/bank/link-token`** (Protected)
  Generates the initialization URL and Customer ID to launch the Mono Connect widget on the frontend.
* **`POST /api/bank/exchange-token`** (Protected)
  Takes the `publicToken` generated by the frontend widget and securely exchanges it for a permanent, encrypted Bank Access Token.
* **`POST /api/bank/webhook`** (Public - Signature Verified)
  Listens for Mono server events (e.g., account de-authorization). Secured via `mono-webhook-secret` header.
